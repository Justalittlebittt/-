# 动物拼图游戏（AI 游戏开发）

原创动物园主题二维多格动物拼图游戏。玩法参考多格拼块填充的机制思想，但动物形象、关卡、美术与内容均为原创。

> **仓库为项目的协作事实源。** 美术 AI 与开发 AI 分页工作，通过本仓库中的合同、状态与结构化交接协同。人类主要负责视觉审美验收；技术检查和常规修复由 AI 在各自职责内完成。

## 核心约束
1. `occupied_cells` 只表示**二维画面中的逻辑拼块格子**，与动物的三维地面投影或脚掌面积无关。
2. 动物视角、朝向、站卧姿态和形体抽象可变；造型服务于物种辨识、可爱感与合法拼块轮廓。不得强制统一俯视或统一短腿大肚子。
3. 美术统一**偏真实的动画电影式CG材质与照明品质**，保留精细的内部皮毛/斑纹质感；外轮廓及抠图Alpha独立控制。
4. ART / EXPERIENCE 负责视觉方案、风格、母版和视觉候选；DEV / INTEGRATION 负责逻辑占格、技术加工、自动测试、运行时接入与技术修复。每个具体任务只有一个 Owner。
5. 视觉是否获批必须有用户明确确认；G1/G2/G4 技术验收必须有实际运行证据，未测试标为 `NOT RUN`。
6. 当前完整**可发布**首版开发周期上限为7天（暂时性硬约束）；首版仅运输与入园章节。
