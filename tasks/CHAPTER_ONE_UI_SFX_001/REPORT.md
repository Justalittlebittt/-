# 第一章4条A版操作音效接入

2026-10-30，V1.6 §14及HUMAN“接入”。桌面旋转动物.wav、放置成功.wav、放置失败.wav、关卡完成.wav均与合同指定Soundza /g/链接返回的RIFF WAV原字节完全一致；链接是直接文件而非HTML页面。原字节、来源和SHA-256见assets.json。没有生成或接入通用拿起音效。

## 实现

复用animalAudio的同一缓存、错误处理和静音接口，以animal/operation/completion三个瞬时通道区分声音，未增加第二个管理系统。正常动作音效音量为animalAudio.volume的75%（当前0.45），音乐保持0.18。有效90°旋转一次一声，拒绝旋转静默；合法落位一次成功声；棋盘内非法落位一次失败声，拖回盘外取回及取消静默。最终合法落位仍有成功声，完成声通过独立瞬时通道播放，避免被成功声立即截断。完成声每关每次开始/重置仅一次，绘制、重复点击、取回再填不重复；新关/重置停止全部瞬时通道并重置完成标志。开始和换关继续保持背景音乐，叫声素材和关卡数据不变。

右上角新增“音效：开/关”，统一控制叫声和4条操作声；与音乐开关、音乐音量独立。播放失败不阻断拖拽或旋转。共4事件，无pickup配置。
